# Computational results

`heuristics/` contains the complete heuristic inputs and summaries for the
revised manuscript, updated on 17 October 2026. Start with
[the heuristic data guide](heuristics/README.md) and its `manifest.json`.

`gurobi/` contains 80 logs, updated on 18 October 2026: 60 for
`n = 100, 150`, `r = 0, 50, 100`, and Instances 1--10; and 20 for
`n = 200, 300`, `r = 50, 100`, and Instances 1--5. See
[the Gurobi data guide](gurobi/README.md) for the manifest and numerical
summaries. The all-node TSP optimum for `E150_1000.10_R0` is 1201, and the
corresponding value in `../reference_values/` has been updated.
